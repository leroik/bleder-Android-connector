# Phone Rotation

Установочные файлы для передачи вращения с Android на выбранный объект в Blender по локальной сети.

## Скачать

- [Аддон Blender](../../releases/latest/download/PhoneRotation-Blender.zip)
- [Приложение Android](../../releases/latest/download/PhoneRotation.apk)
- [Все версии](../../releases)

Установите ZIP через **Edit → Preferences → Add-ons → Install from Disk**. В 3D View откройте **N → Phone Rotation**, выберите объект и нажмите **Start pairing**. На телефоне откройте приложение и отсканируйте QR-код. Телефон и компьютер должны быть в одной локальной сети.
