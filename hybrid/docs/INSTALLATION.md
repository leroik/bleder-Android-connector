# Установка и первый скан

## Windows

1. Установите CPython 3.12 x64 с Python Launcher (`py`) и, если Open3D сообщает об отсутствии DLL, [Microsoft Visual C++ Redistributable x64](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist).
2. Распакуйте ZIP Scan Engine. Запустите `Setup-Windows.cmd`. При первой установке pip скачивает библиотеки, включая Open3D. Для полностью офлайн-установки на Windows x64 заранее скачайте колёса командой `py -3.12 -m pip download -r pc_engine\requirements-windows.lock -d wheelhouse`, перенесите их и установите в venv с `--no-index --find-links wheelhouse`.
3. Запустите `Start-Scanner.cmd`. Оставьте окно открытым. В брандмауэре разрешите TCP 8765 только для частной сети. Если автодетект выбрал VPN, запустите через терминал `Start-Scanner.cmd --host 192.168.1.23` с IPv4 вашего ПК. Код и токен отображаются в этой консоли.
4. Движок хранит сеансы в `scans/<UUID>/` рядом с запускным скриптом. При необходимости укажите `--data D:\Scans`. Для настроек вызовите `.venv\Scripts\python.exe -m pc_engine --settings pc_engine/settings.example.json serve` и измените копию файла настроек.

## Android

1. Установите `HybridScanner-0.1.0-debug.apk` с разрешением установки из выбранного приложения или через `adb install`. APK подписан отладочным ключом и предназначен для разработки. Android 8.0+ указан в манифесте, а захват требует ещё ARCore и Depth API. Телефон и Windows должны быть в одной Wi-Fi/LAN.
2. Откройте **Hybrid 3D Scanner**, разрешите камеру. При необходимости установите или обновите Google Play Services for AR. Первичная установка ARCore может потребовать интернет; сетевой обмен сканами идёт локально.
3. Нажмите **QR**, наведите камеру на код из окна ПК и коснитесь кода в предпросмотре телефона, если он размытый. После чтения приложение автоматически вернётся к основному экрану. Если терминал плохо отображает QR или телефон не читает его, используйте **Код ПК** и вставьте строку `h3s1:…`.
4. Поместите матовый неподвижный объект при рассеянном свете, начните с расстояния 0,5–1,5 м. Медленно двигайтесь вокруг объекта. Оставляйте перекрытие между видами. Depth показывает текущий кадр, «Точки» и Mesh показывают накопленную геометрию с ПК. Пауза сохраняет координатный сеанс, пока приложение не закрыто.
5. Нажмите **Завершить**. Дождитесь ACK для всех записанных кадров и окончания очереди. В **Сеансы** выберите скан, чтобы открыть сохранённый предпросмотр, повторить передачу, сохранить PLY/GLB или удалить локальные файлы. Экспорт вызывается на ПК. Копия ранее загруженного экспорта сохраняется на телефоне.

## Blender 4.2+

1. **Edit → Preferences → Add-ons → Install from Disk**, укажите ZIP Scanner и включите аддон. При запросе Blender разрешите локальную сеть. В 3D View откройте **N → 3D Scanner**.
2. Для Blender на том же ПК оставьте `http://127.0.0.1:8765`, вставьте строку **Token** из консоли движка. Адрес отличается от QR-пакета, в поле токена нужна только его последняя часть.
3. Наблюдайте точки, траекторию и TSDF Preview. Начать с панели можно после спаривания Android; при остановке Blender запрашивает у подключённого телефона завершение записи и догрузку. При потере телефона повторная остановка доступна после таймаута статуса.
4. После завершения выберите PLY/GLB и нажмите **Импорт** или **Экспорт**. Геометрия импортируется в текущую сцену. При необходимости кадрируйте объект или уменьшите масштаб области просмотра.

## Офлайн-повтор и диагностика

```powershell
.venv\Scripts\python.exe -m pc_engine replay scans/<UUID> --output rescan.ply
.venv\Scripts\python.exe -m pc_engine replay scans/<UUID> --poses poses.json --output corrected.glb
```

`poses.json` — объект `{"42":[16 чисел]}`: ключ — frame ID, матрица задаётся в исходной системе ARCore Camera-to-World, row-major. Берите изменённые позы из проверенной внешней оптимизации. Используйте отдельный каталог результатов для сравнения. На ПК `<UUID>` замените без угловых скобок.

- **Нет связи.** Проверьте, что IP соответствует Wi-Fi, сеть разрешает обмен между клиентами, порт открыт, а QR снят после последнего перезапуска Scan Engine.
- **Записано, но ACK не растёт.** Проверьте состояние ПК и сеанса. Во время потери Wi-Fi файлы остаются на телефоне. Вернувшись в сеть, оставьте приложение на экране и экспортируйте после завершения очереди. После перезапуска ПК отсканируйте новый QR, затем передайте сохранённый сеанс.
- **Tracking есть, глубины мало.** Двигайтесь медленно в боковом направлении, увеличьте освещение и выберите объект с видимой фактурой. На неподдерживаемом телефоне захват будет недоступен.
- **Облако есть, сетки мало.** Сделайте больше перекрывающихся ракурсов в пределах рабочего диапазона. Поверхность TSDF требует соседних наблюдений. Экспорт PLY может вернуть облако; GLB требует сетку.
- **Лимит очереди/глубины/TSDF.** Смотрите Fusion и Mesh в Blender и сообщения движка. Увеличение вокселя уменьшает расход памяти, но снижает детализацию. Изменённые настройки проверьте через `replay`.

## Сборка

JDK 21, Android SDK 35, Build Tools 35.0.0, Gradle 8.11.1.

```text
gradle -p hybrid/android :app:assembleDebug
# APK для установки рядом с ранее подписанной debug-сборкой
gradle -p hybrid/android :app:assembleDebug -PscannerSideBySide
python hybrid/scripts/package.py --out dist --apk hybrid/android/app/build/outputs/apk/debug/app-debug.apk
```

Конфигурация `.github/workflows/hybrid-scanner.yml` собирает debug APK, гоняет тесты движка на Windows/Linux и публикует ZIP в артефакты workflow.
